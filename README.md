### 📈 Prediction of AQI Using Time Series Across Indian Cities (SARIMA)

This project focuses on forecasting **Air Quality Index (AQI)** across major Indian cities using **time series modeling techniques**, specifically **Seasonal ARIMA (SARIMA)**. The objective is to understand pollution trends and build accurate models for short-term AQI prediction, aiding public health planning and environmental monitoring.

**Key Features:**

* 📊 **Exploratory Data Analysis (EDA)** on historical AQI data across multiple Indian cities
* 🕒 **Time Series Decomposition** to study trend, seasonality, and residuals
* 🔁 **SARIMA Modeling** for forecasting city-wise AQI levels
* ✅ **Model Diagnostics & Evaluation** using AIC, RMSE, and residual analysis
* 📍 **City-wise Comparisons** of model performance and AQI trends

**Tools & Libraries:**
Python, pandas, statsmodels, matplotlib, seaborn, plotly
